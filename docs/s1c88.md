# Epson S1C88 — reference notes

The S1C88 is the 8-bit CPU core of the **Pokémon Mini**. sdcc88's backend (`src/s1c88/`) compiles C to it.

## Authoritative reference set → [`docs/s1c88/`](s1c88/README.md)

The distilled, comprehensive reference lives in **[`docs/s1c88/`](s1c88/README.md)** — a topic-split
set transcribed from the **Epson official manuals**:

- **S1C88 Core CPU Manual** (MF658-05) → [architecture](s1c88/architecture.md),
  [memory model & banking](s1c88/memory-model.md),
  [CPU operation & interrupts](s1c88/cpu-operation-interrupts.md),
  [addressing modes](s1c88/addressing-modes.md), [instruction set](s1c88/instruction-set.md).
- **Tool Package Manual I** (S5U1C88000C) → [C compiler & ABI](s1c88/c-compiler.md),
  [assembler `as88`](s1c88/assembler.md), [linker `lk88`](s1c88/linker.md),
  [locator `lc88` & DELFEE](s1c88/locator-delfee.md), [utilities & file formats](s1c88/utilities.md),
  [toolchain overview](s1c88/toolchain.md).

Source PDFs: `docs/s1c88-core-cpu-manual.pdf` (Core CPU Manual, MF658-05) and the Epson **S5U1C88000C**
Tool Package Manual. See [`docs/s1c88/README.md`](s1c88/README.md) for provenance and how to regenerate
the text extraction.
