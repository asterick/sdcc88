# Epson S1C88 — reference notes

The S1C88 is the 8-bit CPU core of the **Pokémon Mini**. skip-c's backend (`src/s1c88/`) compiles C to it.

## Encoding & ISA references (reused from skiploom)

The sibling project `../skiploom` already did the ISA legwork:

- **`../skiploom/src/util/s1c88.csv`** — machine-readable opcode/operand table. This is the primary source
  for instruction selection in `gen.c` and for sizing/encoding. (skiploom generates its assembler's lookup
  tables from this CSV via `src/util/table.js`.)
- **`../skiploom/docs/id000920.pdf`** — Epson S1C88 core technical manual (registers, addressing modes,
  instruction semantics, timing).

## Assembly syntax

skiploom assembles **AS88** syntax (the Epson toolchain dialect), labels local by default. If skip-c emits
assembly for skiploom to assemble/link, `gen.c` must produce AS88-compatible mnemonics and directives. See
`../skiploom/README.md` and its `CLAUDE.md` for AS88 differences.
